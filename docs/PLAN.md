# خطة تنفيذ B-Auth

## 1. الهدف
تشغيل مشروع B-Auth كـ Monorepo يحتوي على واجهة Vite وخادم Express وحزم مشتركة، مع توثيق قابل للاستكمال بين الجلسات.

## 1.1 نتيجة المراجعة بتاريخ 27/08/2026
- الهدف الأساسي اتحقق: المشروع مستعاد من `b-auth-04.zip`، قابل للتثبيت، مع حذف الأسرار وملفات البناء وبيانات التشغيل.
- الخطة القديمة كانت بتعرض مراحل تأسيس وجودة كأنها لسه مفتوحة؛ تم اعتبارها منفذة بناءً على `docs/AI_SESSION.md` ونتائج التحقق المسجلة.
- الخطة النشطة الآن هي `v0_plans/practical-scope.md` الخاصة بإعادة تصميم Splash/Auth وتفعيل الترجمة RTL/LTR، ولسه محتاجة تنفيذ ومراجعة مستقلة.

## 3. قرارات العمل
- نبدأ من المشروع المستعاد كما هو، ولا نخلط Next.js مع Vite.
- لا نضيف Redis أو Queue أو GraphQL بدون احتياج فعلي.
- نستخدم REST للـ auth والـ health والـ storage.
- أي قرار متعارض يتوقف عنده التنفيذ ويُطلب اعتماد المستخدم.

## 4. Definition of Done
المهمة تعتبر مكتملة لما تكون الملفات محدثة، typecheck/lint ناجحين، المسار الأساسي متجرب، والتوثيق محدث.
